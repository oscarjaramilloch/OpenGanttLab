1. Introducción

OpenGanttLab te permite ver y comparar cronogramas de proyecto en tres formatos: un Gantt comparador de escenarios, una Línea de Tiempo lista para presentar y una Tabla de Datos editable. Funciona en un único archivo HTML, sin instalación y sin conexión a internet: tus datos no salen de tu computador.

Trabaja con archivos Excel (.xlsx) con varios escenarios o con archivos XML de Microsoft Project (incluso de más de 1 GB).

Navegador: usa Chrome o Edge (versión 86 o superior). Guardar los cambios directamente en el Excel requiere una función propia de estos navegadores.
Contenido: 1. Introducción 2. Primeros pasos 3. Conociendo la pantalla 4. Cargar tus datos 5. Importar desde Project XML 6. Editar en la Tabla de Datos 7. Usar el Gantt 8. Armar la Línea de Tiempo 9. Exportar y compartir 10. Configuración 11. Atajos 12. Problemas frecuentes

2. Primeros pasos

El camino habitual, de principio a fin:

  1. Carga tus datos (Excel o Project XML) desde Datos.
  2. Revísalos y corrígelos en la Tabla de Datos si hace falta.
  3. Compara escenarios en el Gantt (Comparador de Escenarios).
  4. Arma la presentación en Línea de Tiempo: colores, textos, hitos, leyenda.
  5. Exporta a PNG, PDF o PowerPoint, o comparte un archivo HTML que se abre solo, sin el Excel.
Consejo: si abres OpenGanttLab por primera vez y ves un mensaje de bienvenida, pulsa Iniciar. Si el Gantt está vacío, haz clic en él para vincular tu archivo.

3. Conociendo la pantalla

El menú lateral (riel izquierdo)

SecciónPara qué sirve
Comparador de EscenariosEl diagrama de Gantt: barras de Línea Base contra Real/Proyectado, por escenario.
Línea de TiempoVista ejecutiva para presentar: hitos, barras y textos que puedes editar libremente.
DatosLa Tabla de Datos, la carga de archivos y la Gestión de XML.
ConfiguraciónTema, recordatorios y valores por defecto.
AyudaEste manual.

El botón « Colapsar reduce el menú a solo íconos para ganar espacio.

La barra de herramientas

Cada sección tiene su propia barra arriba. Hay dos tipos de controles:

  • Interruptores (toggles): se activan o desactivan con un clic (por ejemplo Línea Base, Resumen, Leyenda).
  • Íconos con flecha «˅»: abren un menú con más opciones (Filtro, Edición, Exportar…). Pasa el cursor sobre cualquier ícono para ver su nombre.

La barra de estado

Al pie de la pantalla muestra información del proyecto y el botón Ir a hoy cuando aplica.

4. Cargar tus datos

Desde un Excel (.xlsx)

El archivo debe tener estas columnas, en este orden:

ColumnaQué contiene
idIdentificador de la tarea.
Categoría 1El escenario (por ejemplo, «Plan A», «Plan B»).
Categoría 2La fase o agrupación de la tarea.
Nombre de TareaEl texto que se verá en el Gantt.
Start LB / End LBInicio y fin de la Línea Base.
Avance %De 0 a 100, o de 0.0 a 1.0.
Start R/P / End R/PInicio y fin Real/Proyectado.
Clase«Hito» o «Tarea».
Ruta Crítica«Si» o «No».

Pasos:

  1. Ve a Datos en el menú lateral.
  2. Pulsa el ícono Cargar archivo (flecha hacia arriba). Detecta solo si es .xlsx o .xml.
  3. Elige tu archivo. Las tareas aparecen en la tabla y en el Gantt.

Cuando el Excel queda vinculado, aparece el botón Actualizar (flechas circulares): vuelve a leer el archivo con los últimos cambios que hayas guardado en Excel.

5. Importar desde Project XML

  1. En Datos, pulsa Cargar archivo y elige uno o varios archivos .xml (también puedes arrastrarlos). Una barra muestra el avance de lectura; los archivos muy grandes tardan más.
  2. Abre Gestión de XML (Base de datos) desde la flecha junto a Cargar archivo. Allí ves cada archivo cargado.
  3. Revisa el Mapeo de columnas: para cada campo de la tabla (Escenario, Categoría 1, Nombre de Tarea, Start LB, etc.) elige la columna del XML de donde tomar el dato, escribe un Valor fijo o usa la Variante del archivo.
  4. Usa Vista previa para comprobar las primeras tareas con tu mapeo antes de aceptar.

Herramientas de la Gestión de XML

  • Duplicar escenario: copia una carga con su propio mapeo, para probar otra configuración sin volver a leer el archivo.
  • Eliminar escenario (papelera): quita la carga y sus tareas de la tabla. Pide confirmación.
  • Copiar al [n]: lleva el mapeo de un archivo al siguiente.
  • «+» Agregar mapeo personalizado: crea una columna extra con el nombre que quieras.
  • Exportar: descarga toda la base como CSV.
Línea base actual: Project guarda hasta 11 líneas base (0 a 10). El programa usa por defecto la de fecha de guardado más reciente y lo indica como «LB actual: N».
Las columnas personalizadas duran solo la sesión: no viajan con Compartir ni se exportan a Excel.

6. Editar en la Tabla de Datos

  • Editar: haz clic en una celda y escribe. Los cambios se aplican solos; el Gantt y la Línea de Tiempo se actualizan al salir de la tabla.
  • Agregar fila: botón Agregar fila en la barra.
  • Deshacer / Rehacer: botones de flecha en la barra.
  • Restaurar: vuelve a los datos originales del XML y descarta tus cambios manuales.
  • Filtrar: menú Filtro → activa los filtros por columna (ícono de embudo en cada encabezado).
  • Ancho de columna: arrastra el borde derecho del encabezado.
  • Guardar en el Excel vinculado o Descargar .xlsx para llevarte los cambios.
Con miles de tareas la tabla sigue fluida: solo dibuja las filas visibles. El nombre de la tarea se ve en una línea y se expande al editarlo.

7. Usar el Gantt (Comparador de Escenarios)

Mostrar y ocultar elementos

InterruptorEfecto
Avance realRellena cada barra según su porcentaje de avance.
Línea BaseMuestra la barra de Línea Base junto a la Real/Proyectada.
Marca ActivityResalta las tareas marcadas como Activity.
ResumenMuestra las tareas resumen (viene apagado).
FechasEscribe las fechas junto a las barras.
Fecha de estadoDibuja una línea vertical en la fecha de corte; su menú cambia estilo, grosor y color.
Ruta CríticaMarca con borde rojo las tareas críticas; su menú ajusta el grosor.

Ordenar, filtrar y seleccionar

  • Orden de tareas: Cronológico o Original (el del archivo).
  • Filtro: filtros por columna; Borrar los quita todos.
  • Selección de tareas: elige qué tareas y categorías se ven.

Editar desde el Gantt (menú Edición)

  • Insertar texto: agrega una nota libre sobre el diagrama.
  • Mover en bloque: desplaza por N días las fechas de todas las tareas de un escenario o categoría.
  • Reordenar grupos: cambia el orden visual de escenarios y categorías con las flechas ▲▼.

Trucos con el mouse

  • Pasa el cursor sobre una barra o hito para ver sus fechas, avance y si es crítica.
  • Clic en un nombre de Categoría 1, Categoría 2 o Escenario para cambiar su color.
  • Clic derecho en un encabezado: elige qué columnas mostrar u ocultar (incluidas las personalizadas) y si el texto se ajusta a 2 líneas o se corta con «…».
  • Arrastra el borde derecho de un encabezado para cambiar el ancho de la columna.
  • El botón Fuente cambia la familia y el tamaño del texto del Gantt y de la Línea de Tiempo.

8. Armar la Línea de Tiempo

Es la vista pensada para presentar. Toma los datos de la tabla y te deja retocarla a mano sin alterarlos.

Controles principales de la barra

ControlEfecto
ComparadorMuestra línea base y escenario alternativo en filas separadas.
SegmentaciónAgrupa por Categoría 2.
LeyendaCuadro con el color de cada categoría; se arrastra y se redimensiona.
EjecutivoCada tarea se dibuja como un rombo en su fecha fin, con nombre y fecha debajo.
Vista C1Agrupa las barras en bandas por Categoría 1.
Vista HitosMuestra solo los hitos y oculta las barras.
FechasMuestra las fechas de las barras.
Fecha de estado / Ruta CríticaIgual que en el Gantt.
EscalaAños, Trimestres, Meses o Semanas. El eje se recorta al rango real de tus fechas.

En Configuración (rueda dentada de la barra) ajustas el formato de fecha, el espacio extra alrededor del diagrama, el tamaño de los rombos y el ancho del eje de años. En Escenario y títulos eliges el escenario a mostrar y editas los títulos.

Editar elementos

  • Un clic en una barra, hito o evento: lo selecciona (borde punteado azul). Con Delete lo oculta de la Línea de Tiempo.
  • Doble clic: abre el panel de edición (color, texto, fechas, alineación, negrita/cursiva/subrayado, posición, capa).
  • Arrastrar: mueve la barra o el hito.
  • Selección múltiple: Ctrl o Shift + clic. El doble clic edita todas a la vez y arrastrar una mueve el grupo.
  • Clic en un espacio en blanco: limpia la selección.
  • Clic en un año: cambia el color de fondo y la fuente del año.
Editar el texto o el color en la Línea de Tiempo es solo visual: nunca cambia tus datos de la Tabla, el Gantt, el Excel o el XML.

Agregar elementos libres

En el menú Edición: Insertar texto e Insertar forma (rectángulo, óvalo, rombo, estrella, flecha, línea y otras). Cada forma se arrastra, se redimensiona con las asas de las esquinas, se gira libremente y puede llevar texto dentro. El menú también tiene Reset Diagrama, que devuelve todas las barras al color de su Categoría 2.

Vista Ejecutivo

  1. Activa Ejecutivo.
  2. Para quitar una tarea de esta vista: selecciónala y pulsa Delete (o doble clic → Ocultar de Ejecutivo).
  3. Junto al interruptor aparece Tareas ocultas (N): ábrelo para restaurar una, o todas.

Zoom

Abajo a la derecha del lienzo hay una barra de zoom (25% a 400%). Pulsa el porcentaje para volver a 100%.

10. Configuración

  • Apariencia: tema claro u oscuro y pestaña con la que se abre la aplicación.
  • Recordatorios: aviso de cambios sin compartir cada N minutos (0 lo desactiva).
  • Datos y métricas: cómo se muestra el avance en los tooltips (porcentaje o días), grosor del borde de la Ruta Crítica y paleta de colores por defecto.
  • Editor de Datos: qué columnas se ven en la Tabla de Datos.

12. Problemas frecuentes

El Gantt aparece vacío

Aún no hay datos cargados. Ve a Datos y usa Cargar archivo.

No veo la Línea Base

Activa el interruptor Línea Base (Gantt) o Comparador (Línea de Tiempo), y revisa que Start LB y End LB tengan fechas.

Faltan tareas en el Gantt

Revisa los filtros por columna (usa Borrar), la Selección de tareas y que Resumen esté activado si buscas tareas resumen. En la Línea de Tiempo, mira Tareas ocultas (N).

Las fechas salen mal o no salen

Verifica que las columnas de fecha del Excel sean fechas reales y no texto. También puedes cambiar el formato de fecha en la Configuración de la Línea de Tiempo.

El XML es enorme y tarda

Es normal: se lee por partes y la barra de progreso muestra el avance. Un archivo de 1.7 GB puede tardar de 35 a 80 segundos.

No puedo guardar en el Excel

Usa Chrome o Edge y vincula el archivo desde Datos. Como alternativa, usa Descargar .xlsx.

PPTX no se genera

La primera vez necesita conexión a internet para descargar el componente de exportación.

Perdí mis cambios de la Línea de Tiempo

Usa Compartir para guardar una copia completa. Las tareas ocultas de Ejecutivo y el formato de fecha también se recuerdan por proyecto en el navegador.

¿Qué es OpenGanttLab?

Herramienta standalone (HTML único, sin internet) para visualizar y comparar cronogramas de proyectos. Lee archivos Excel (.xlsx) con múltiples escenarios o archivos XML de Microsoft Project (incluso de más de 1 GB) y genera un Gantt interactivo, una tabla de datos editable y una línea de tiempo de presentación.

Formato del Excel de entrada

Columnas requeridas (en orden): id, Categoría 1 (escenario), Categoría 2 (fase), Nombre de Tarea, Start LB, End LB, Avance % (0-100 ó 0.0-1.0), Start R/P, End R/P, Clase ("Hito" o "Tarea"), Ruta Crítica ("Si"/"No").

Navegación

  • El riel izquierdo tiene cinco secciones: Comparador de Escenarios (Gantt), Línea de Tiempo, Datos, Configuración y Ayuda. El botón «« / Colapsar lo reduce a solo íconos.
  • Cada sección tiene su propia barra de herramientas arriba. Los interruptores (toggles) se activan con un clic; los íconos con «˅» abren un menú.

Comparador de Escenarios (Gantt)

  • Interruptores: Avance real (relleno de avance en las barras), Línea Base, Marca Activity, Resumen (mostrar las tareas resumen), Fechas (fechas junto a las barras), Fecha de estado y Ruta Crítica (borde rojo).
  • Actualizar: recarga el Excel vinculado con los últimos cambios.
  • Orden de tareas: Cronológico u Original (orden del archivo) dentro de cada Categoría 2.
  • Filtro: activa/desactiva los filtros por columna (ícono de embudo en cada encabezado) y «Borrar» los quita todos.
  • Selección de tareas: elige qué tareas y categorías se ven.
  • Edición: Insertar texto libre, Mover en bloque las fechas de un grupo y Reordenar grupos.
  • Fuente: familia y tamaños del Gantt y de la Línea de Tiempo.
  • Compartir: genera un HTML autónomo con los datos embebidos (sin necesidad del Excel/XML).
  • Interacción: clic en Categoría 1/Categoría 2/Escenario cambia su color; el cursor sobre una barra o hito muestra fechas LB, R/P, avance y ruta crítica; el borde derecho de un encabezado se arrastra para cambiar el ancho de la columna.

Gantt — columnas (clic derecho en un encabezado)

  • Mostrar / Ocultar: una sola lista con todas las columnas de la Tabla de Datos: Escenario, Categoría 1, Categoría 2, Marca Activity, Nombre de Tarea, Start LB, End LB, Avance Real, Start R/P, End R/P, Clase, Ruta Crítica, Resumen y las columnas personalizadas que se creen en el mapeo de XML. Las de la izquierda están visibles por defecto; las demás, ocultas.
  • Las columnas que se agregan quedan fijas a la izquierda, a continuación de «Nombre de Tarea», con su propio botón de filtro y ancho ajustable arrastrando el borde. Las fechas se muestran como dd/mm/aaaa.
  • Ajustar texto (ícono al inicio del menú): se aplica a la columna donde hiciste clic derecho. Activo = el texto se ajusta a 2 líneas; inactivo = una sola línea que termina en «…» si no cabe. La preferencia se guarda por columna.
  • Altura de fila automática: cada fila mide el mínimo necesario para mostrar su texto (1 o 2 líneas según lo que realmente ocupe en el ancho de la columna) y sus barras o hitos. Las barras (LB y R/P) y los hitos miden 12 px y quedan centrados verticalmente.

Datos — Tabla de Datos

  • Barra de herramientas: Restaurar los datos originales del XML, Deshacer / Rehacer, Cargar archivo (Excel o Project XML; detecta la extensión), Más opciones de carga (incluye Descargar plantilla), Guardar cambios en el Excel vinculado, Descargar .xlsx, Agregar fila, Filtro y Compartir.
  • Columnas: Escenario, Categoría 1, Categoría 2, Nombre de Tarea, Start LB, End LB, Avance Real, Start R/P, End R/P, Clase, Ruta Crítica, Marca Activity y Resumen, más las columnas personalizadas del mapeo de XML (al final). El ancho de cada columna se ajusta arrastrando el borde del encabezado.
  • Edición y autoguardado: los cambios se aplican solos. Con la tabla abierta el Gantt y la Línea de Tiempo no se repintan en cada tecla: se actualizan al salir de la tabla. Deshacer y Rehacer están en la barra de herramientas.
  • Tablas grandes: desde 250 filas solo se dibujan las visibles (más un margen), por lo que se mantiene fluida con miles de tareas. En ese modo el nombre de la tarea se ve en una línea y se expande al editarlo.
  • Columnas personalizadas de fecha: si todo su contenido son fechas, la columna es de tipo fecha (selector de calendario y filtro por año, mes y día).

Datos — Gestión de XML (Microsoft Project)

  • Cargar XML: arrastra o elige uno o varios archivos .xml. El archivo se lee por partes (streaming), por lo que soporta XML de más de 1 GB: solo se conserva el proyecto, los campos personalizados, cada tarea y las líneas base; se descartan asignaciones, recursos, calendarios y el time phasing. Una barra de avance muestra el porcentaje leído.
  • Líneas base 0–10: por cada tarea se guarda el Comienzo y el Fin de las 11 líneas base. La línea base actual es la de fecha de guardado más reciente (campos «Baseline N saveddate»); si el proyecto no los trae, la marcada para valor ganado, o la 0. Se muestra como «LB actual: N» en Base de datos y en las columnas «LB actual / Inicio / Fin». El mapeo automático de Start LB / End LB usa la línea base actual.
  • Base de datos: lista de archivos cargados. El nombre (variante) es editable; los íconos permiten Duplicar escenario (copia la carga con su propio mapeo para probar otro sin volver a leer el archivo) y Eliminar escenario (quita también sus tareas de la tabla; pide confirmación).
  • Mapeo de columnas: cada archivo tiene su propio mapeo independiente (buscador de columna, «Variante del archivo» o «Valor fijo»). Si Escenario está en «Valor fijo», la carga se renombra con ese valor y viceversa. El campo de valor fijo crece con el texto. «Copiar al [n]» copia el mapeo al siguiente archivo.
  • Mapeo personalizado (ícono «+»): crea una columna extra con nombre editable en la Tabla de Datos y en el Gantt (clic derecho). Solo dura la sesión: no viaja con Compartir ni se exporta a Excel.
  • Vista previa muestra las primeras tareas con el mapeo aplicado, y Exportar descarga toda la base como CSV (incluye las líneas base 0–10).

Configuración

  • Apariencia: tema oscuro y pestaña de inicio.
  • Recordatorios: aviso de cambios sin compartir cada N minutos (0 = desactivado).
  • Datos y métricas: avance en tooltips del Gantt (porcentaje o días), ancho de borde de la Ruta Crítica y paleta de colores por defecto (Categoría 1, Categoría 2 y Escenario).
  • Editor de Datos: qué columnas se ven en la Tabla de Datos.

Línea de Tiempo — Vista ejecutiva

  • Escala: Años, Trimestres, Meses o Semanas. El eje se recorta automáticamente al rango real de fechas de las tareas (sin períodos vacíos al inicio o al final).
  • Formato fecha: 11 formatos disponibles (mm/aa, dd/mm/aa, dd/mm/aaaa, etc.). Se aplica al Gantt y a la Línea de Tiempo mediante el mismo selector global.
  • Opciones: Segmentación (agrupa por Cat2), Línea Base, Leyenda.
  • Fecha de estado: Línea vertical con estilo, grosor y color configurables.
  • Ruta crítica — Borde: Grosor del borde en elementos críticos.
  • Un clic en barra, hito o evento: solo selecciona el elemento (queda resaltado con borde punteado azul) y lo deja listo para Delete.
  • Doble clic en barra, hito o evento: abre el panel de edición (color, texto, fechas, alineación, negrita, capa ▲▼, posición).
  • Clic en espacio en blanco: limpia la selección actual.
  • Clic en año: color de fondo y fuente del año.
  • Insertar texto / forma: Elementos gráficos libres sobre la línea de tiempo.
  • Deshacer / Rehacer: Ctrl+Z / Ctrl+Y para revertir cambios en la Línea de Tiempo.

Línea de Tiempo — Vista Ejecutivo

  • Activar: Checkbox "Ejecutivo" en Visualización. Cada tarea se representa como un rombo en su Fecha Fin, con el nombre y la fecha centrados debajo (igual que los hitos reales); los hitos y eventos del proyecto conservan su posición habitual.
  • Ocultar una tarea solo de Ejecutivo: selecciónala (un clic) y presiona Delete, o dóble clic → botón "Ocultar de Ejecutivo". No se modifica el dato: sigue existiendo en el Gantt, el Excel y el XML.
  • Tareas ocultas (N): enlace junto al checkbox Ejecutivo; abre el listado de tareas ocultas con opción de restaurarlas una a una o todas.
  • Persistencia: las tareas ocultas y el formato de fecha elegido se guardan automáticamente por proyecto (localStorage) y también quedan incluidos al usar "Compartir", por lo que se conservan al cerrar/reabrir el archivo o al abrirlo en otro equipo.
Compatibilidad: Optimizado para Chrome y Edge 86+. Guardar en Excel requiere la API File System Access.

Un XML de 1.7 GB se lee en unos 35–80 s con memoria acotada. Barra de avance de carga.
