Qué es un escenario

Un escenario es una versión del cronograma que quiere comparar: un plan base y una replanificación, o las variantes P10, P50 y P90 de una simulación. Cada escenario tiene sus propias tareas.

El escenario de una tarea se determina así, en este orden:

  1. La columna Escenario de la tarea, si tiene valor.
  2. Si no, el archivo XML de origen (cada XML cargado cuenta como un escenario, con el nombre de su variante).
  3. Si no, su Categoría 1. Así, un Excel antiguo que usa la Categoría 1 para las versiones sigue funcionando sin cambios.

El escenario es también el ámbito de los ID de las dependencias: dos escenarios pueden repetir los mismos ID sin mezclarse.

Gestión de escenarios

La sección Datos tiene una pestaña Gestión de escenarios con la lista de todos los escenarios de la sesión, vengan de Excel o de XML.

Eliminar un escenario quita todas sus actividades de la tabla. Puede deshacerlo desde la Tabla de Datos con Deshacer.

Cargar varios escenarios

  1. Cargue cada varianteEn Datos → Gestión de XML cargue un XML por variante (o varios a la vez). Con Excel, use una fila por tarea y escenario, con la versión en la columna Escenario.
  2. Nombre la cargaEn la pestaña Base de datos del XML edite el nombre de la variante (por ejemplo «P50»).
  3. Revise el mapeo de cada archivoCada archivo tiene su mapeo independiente. Con Copiar al [n] lleva el mapeo al siguiente.

En la Base de datos de XML, el ícono Duplicar escenario copia una carga con su propio mapeo, para probar otra configuración sin volver a leer el archivo (útil con XML muy grandes). El ícono de papelera elimina la carga y sus tareas, con confirmación.

Elegir qué se ve

En el Gantt, abra Filtrar → Selección de tareas. Allí marca qué Categorías 1 (la lista «Escenarios»), qué Categorías 2 y qué tareas se ven. La leyenda de colores y la barra de estado se recalculan con lo que queda visible. Más detalle en Selección de tareas.

La lista «Escenarios» del panel de selección del Gantt muestra las Categorías 1, cada una con su color. Para filtrar por el escenario en sentido de esta página (columna Escenario) use el segmentador de la Tabla de Datos o, en la Línea de Tiempo, el menú Escenario.

En la Línea de Tiempo, el menú Escenario filtra por el escenario y edita los títulos de las secciones; su Selección de tareas ofrece las mismas opciones que la del Gantt.

Comparar escenarios

Hay dos formas complementarias de comparar:

  • Entre escenarios: active varios escenarios a la vez en el Gantt. Cada uno se distingue por el color de su Categoría 1.
  • Contra la línea base: active Línea base para ver, en cada tarea, la barra planificada junto a la real o proyectada. En la Línea de Tiempo, el modo Comparador muestra ambas secciones.

Compare la posición de una misma tarea en dos escenarios (o en la Línea Base y el proyectado): si el fin se corre a la derecha, la tarea se retrasó; si el inicio se corre, se desplazó. La barra de estado muestra el inicio, el fin y la duración del conjunto visible.
