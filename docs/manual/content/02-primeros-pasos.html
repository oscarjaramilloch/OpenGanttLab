• Abrir OpenGanttLab y cargar su primer archivo.
  • Reconocer el flujo de trabajo completo.
  • Hacer un primer recorrido por las tres vistas.

Requisitos

  • Un navegador moderno: Chrome o Edge (versión 86 o superior).
  • Un archivo de cronograma: un Excel (.xlsx) con las columnas que se describen en Proyectos y datos, o un XML exportado desde Microsoft Project.
  • No requiere instalación ni conexión a internet. Solo la exportación a PowerPoint necesita internet la primera vez.

Abrir OpenGanttLab

Abra el archivo OpenGanttLab 3.1.html en el navegador. Aparece una pantalla de bienvenida con los datos del autor y la licencia.

La primera pantalla al abrir la aplicación.

El flujo de trabajo

Casi todo el trabajo sigue el mismo recorrido de cinco etapas. Puede repetir cualquiera de ellas: al corregir un dato, las vistas se actualizan.

Importar, revisar, comparar, presentar y exportar.

Cargar su primer proyecto

  1. Vaya a DatosPulse Datos en el riel de navegación (a la izquierda).
  2. Cargue el archivoPulse el ícono Cargar archivo (flecha hacia arriba). La aplicación detecta sola si es un Excel o un XML. Las dos formas de cargar datos desde la barra de la Tabla de Datos.
  3. Elija el archivoSeleccione su .xlsx o su .xml. Las tareas aparecen en la tabla y, de inmediato, en el Gantt.
  4. Revise los datosCompruebe nombres, fechas y avance en la Tabla de Datos. Puede corregir directamente en ella.
  5. Abra el GanttPulse Comparador de Escenarios para ver el cronograma.

Con el Gantt vacío, un clic sobre el área de trabajo abre un menú para vincular su Excel o importar un XML.

Un XML necesita un paso más: el mapeo de columnas, donde se indica de qué campo del XML sale cada dato. Casi todo se mapea solo. Vea Importar desde Project XML.

Primer recorrido

  1. GanttActive Línea base para ver las barras rayadas junto a las de color, y Avance real para el relleno de avance. Detalles en Cronograma.
  2. DependenciasEn Capas active Dependencias y haga clic en una barra para resaltar su cadena.
  3. Línea de TiempoPulse Línea de Tiempo en el riel. Pruebe Agrupador, Ejecutivo y Vista Hitos. Detalles en Vistas.
  4. ExporteUse Exportar (PNG, PDF o PPTX) Guardar sesión para continuar su trabajo más tarde, o Compartir para enviar un HTML autónomo a otra persona. Detalles en Exportar y compartir.

Al terminar debería ver su cronograma en el Gantt, con los colores de cada Categoría 1 y Categoría 2, y poder pasar a la Línea de Tiempo sin volver a cargar nada.
