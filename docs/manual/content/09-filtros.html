Filtros por columna

  1. Active los filtrosAbra el menú Filtrar y elija Activar/desactivar filtros por columna. Aparece un botón de embudo en cada encabezado.
  2. Abra el filtro de una columnaPulse el embudo del encabezado. Se abre un panel con la lista de valores. Ejemplo con la columna Categoría 2.
  3. Marque los valores y acepteEl Gantt muestra solo las tareas que cumplen todos los filtros activos.
  4. Quite los filtrosCon Borrar filtros del mismo menú.

Según el tipo de columna, las condiciones cambian: texto (es igual a, no es igual a, comienza por, termina con, contiene, no contiene), número (igual, mayor, menor, entre…) y fecha (igual, antes de, después de, entre; con filtro por año, mes y día).

La Tabla de Datos tiene su propio icono Filtro con el mismo panel. Los filtros del Gantt y de la tabla son independientes.

Selección de tareas

La Selección de tareas (menú Filtrar) elige qué Categorías 1, Categorías 2 y tareas concretas se ven en el Gantt.

Seleccione un subconjunto del cronograma.

La Línea de Tiempo tiene el mismo panel, con las mismas opciones.

Orden de las tareas

El menú Ordenar define el orden de tareas e hitos dentro de cada Categoría 2:

Las dos opciones de orden.
OpciónEfecto
CronológicoOrdena por fecha de inicio.
Original (Excel, XML)Respeta el orden del archivo de origen.

Para cambiar el orden de los grupos (Escenario, Categoría 1 y Categoría 2) use Reordenar grupos.

Búsqueda

OpenGanttLab no tiene un buscador global de tareas; la búsqueda se hace dentro de cada filtro de columna (caja «Buscar» del panel) o con el filtro de texto «contiene». Para localizar una tarea, filtre la columna Nombre de Tarea.
