 Cada caso parte de datos ya cargados o por cargar, sigue unos pasos y termina en un resultado concreto.

Caso 1 · ¿Cuánto se desplazó el proyecto?

Situación: el equipo replanificó y el gerente pregunta qué tareas se corrieron respecto al plan original.

  1. Cargue los datosCargue el Excel o el XML con las fechas LB y R/P (Proyectos y datos).
  2. Active Línea base y Avance realEn Capas o con los accesos rápidos de la barra.
  3. Lea los desplazamientosCompare la barra rayada con la de color; agregue las columnas «Start LB», «End LB», «Start R/P» y «End R/P» con clic derecho si necesita las fechas exactas.
  4. Identifique lo críticoActive Ruta crítica para ver solo las tareas marcadas como críticas en los datos del cronograma.

Una vista única con lo planificado, lo proyectado y el avance de cada tarea, donde se ve de inmediato qué se desplazó y cuánto. Vea un ejemplo en Desplazamientos entre Línea Base y proyectado.

Caso 2 · Una lámina para el comité

Situación: hay que presentar el cronograma a un comité en una sola lámina, con foco en los hitos.

  1. Abra la Línea de TiempoElija el modo de vista: Agrupador para agrupar por disciplina, o Ejecutivo para mostrar solo entregas.
  2. Depure lo que se veOculte con Delete las tareas que no aporten, o use Selección de tareas.
  3. Ajuste la presentaciónEdite colores y textos con doble clic; agregue una llamada o una forma desde Editar. Active Leyenda si hace falta.
  4. ExporteExportar → PowerPoint, o PNG para pegarlo en un informe.
Línea de Tiempo con Agrupador, Leyenda y Fecha de estado.

Use Guardar sesión para seguir trabajando la lámina más tarde, o Compartir para enviarla: al abrir el archivo compartido se ve exactamente lo mismo (con las restricciones de edición descritas en Exportar y compartir).

Caso 3 · Revisar la secuencia de un XML de Project

Situación: llega un XML de Project de varios cientos de megabytes y hay que revisar si la lógica está bien enlazada.

  1. CárgueloEn Datos → Gestión de XML. La lectura por partes evita que el navegador se bloquee.
  2. Complete el mapeoConfirme Categoría 1, Categoría 2, Nombre de Tarea y las fechas. Compruebe con la vista previa.
  3. Active las dependenciasEn el Gantt: Capas → Dependencias.
  4. Revise los avisosEl ícono de triángulo lista predecesoras inexistentes y ciclos. Active el aviso de conflictos de fechas en Configuración si quiere comparar también las fechas.
  5. Siga una cadenaHaga clic en un hito importante para resaltar todo lo que lo precede.
Gantt de un XML cargado, con Dependencias activas y un aviso.

Los XML grandes se leen por partes y pueden tardar según su tamaño y el equipo. Una barra muestra el avance durante la carga.
