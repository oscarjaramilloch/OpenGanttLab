Importación

Faltan tareas después de cargar el Excel

Una fila se omite si le falta el Nombre de Tarea, la Categoría 1 o alguna de las fechas de Línea Base. Complete esas columnas y vuelva a cargar. Compruebe también que la primera fila con encabezados esté entre las ocho primeras filas de la hoja.

«No es un .xlsx válido»

El lector solo admite el formato .xlsx. Si el archivo es un .xls antiguo, ábralo en Excel y guárdelo como .xlsx antes de cargarlo.

Las fechas salen mal o no salen

Verifique que las columnas de fecha del Excel sean fechas reales y no texto. Puede cambiar el formato de visualización en el selector de la barra inferior.

El XML es enorme y tarda

Los XML grandes se leen por partes y pueden tardar según su tamaño y el equipo. Una barra muestra el avance durante la carga. No cierre la pestaña mientras carga.

El XML no pasa a la tabla

Los campos Categoría 1, Categoría 2 y Nombre de Tarea del mapeo son obligatorios. Mientras alguno esté vacío, verá el mensaje «Completa los campos obligatorios…» y los datos no se cargan. Asigne una columna o un «Valor fijo» a cada uno.

Mientras falte alguno, los datos no pasan a la Tabla de Datos.

«No parece un XML de Microsoft Project»

El archivo no contiene la sección de tareas de Project. Exporte de nuevo desde Project como XML.

Visualización

El Gantt aparece vacío

Aún no hay datos cargados. Vaya a Datos y use Cargar archivo. Si hay datos, revise que haya Categorías 1 marcadas en Filtrar → Selección de tareas y que no haya filtros activos (Filtrar → Borrar filtros).

Con el Gantt vacío, un clic sobre el área abre el menú de carga.

No veo la Línea Base

Active la capa Línea base (Gantt) o Comparador (Línea de Tiempo) y compruebe que Start LB y End LB tengan fechas.

Faltan tareas en el Gantt

Revise los filtros por columna, la selección de tareas y que Resumen esté activo si busca tareas resumen. Con Marca Activity activo solo se ven las marcadas. En la Línea de Tiempo, mire Tareas ocultas (N).

No veo flechas de dependencias

  • Active Dependencias en Capas.
  • Confirme que las tareas tengan ID y Predecesoras (columnas del Gantt con clic derecho). En XML, revise que el mapeo de «ID (Project)» y «Predecesoras» esté asignado.
  • En la Línea de Tiempo, las flechas no se dibujan en Ejecutivo ni en Vista Hitos.
  • Solo se dibujan entre tareas visibles.

Aparece el ícono de aviso junto a las capas

Es un aviso de calidad de datos, no un error. Haga clic en él para ver las predecesoras inexistentes, los ciclos o, si lo activó, los conflictos de fechas, y corríjalos en la columna Predecesoras de la Tabla de Datos.

Guardar y exportar

No puedo guardar en el Excel

Use Chrome o Edge y vincule el archivo desde Datos. Como alternativa, use Descargar .xlsx.

La exportación a PowerPoint no se genera

La primera vez necesita conexión a internet para descargar el componente de exportación.

Perdí mis cambios de la Línea de Tiempo

Use Compartir para guardar una copia completa. Las tareas ocultas de Ejecutivo y el formato de fecha también se recuerdan por proyecto en el navegador. Las preferencias de Configuración son propias de cada navegador.

Aviso de «cambios sin compartir»

La aplicación no guarda por sí sola si no hay un destino vinculado. Pulse Compartir (o guarde en el Excel vinculado) para conservar el trabajo.

Navegador

OpenGanttLab está optimizado para Chrome y Edge 86 o superior. En otros navegadores puede funcionar, pero algunas funciones (guardar directamente en el Excel, elegir carpeta al compartir) usan una API que no todos incluyen.
