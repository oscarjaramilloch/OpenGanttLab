# OpenGanttLab — Guía de identidad de marca

## 1. Identidad

**Nombre oficial:** OpenGanttLab  
**Nombre de marca para composición visual:** Open Gantt Lab  
**Categoría:** Plataforma de planificación, análisis y control de proyectos.  
**Personalidad:** Profesional, tecnológica, clara, colaborativa y orientada a resultados.

### Propuesta de valor

OpenGanttLab convierte la planificación de proyectos en una experiencia visual, estructurada y accionable, facilitando la creación de cronogramas, el análisis de escenarios, la comparación de alternativas y el seguimiento del avance.

### Concepto de marca

El símbolo combina:

- **Barras de Gantt:** representan actividades, duración y planificación.
- **Línea temporal:** representa orden, secuencia y control.
- **Diamante:** representa un hito, una decisión o un resultado importante.
- **Composición ascendente:** comunica progreso, claridad y avance.

## 2. Construcción del logotipo

### Logo principal

El logo principal está compuesto por:

1. Isotipo de tres barras horizontales.
2. Línea vertical de referencia temporal.
3. Diamante de hito.
4. Wordmark `Open Gantt Lab`.
5. Descriptor opcional: `PLAN · ANALYZE · COMPARE · ACHIEVE`.

El archivo SVG incluido en este paquete es un recurso vectorial real y editable. Sus barras, línea, diamante y textos están construidos como elementos SVG independientes.

### Capitalización oficial

La marca debe escribirse de la siguiente manera:

- **Uso corporativo:** `OpenGanttLab`
- **Wordmark visual:** `Open Gantt Lab`

No utilizar:

- `OPENGANTTLAB`
- `OPEN GANTT LAB`
- `OpenganttLab`
- `open gantt lab`

## 3. Versiones del logo

### 3.1 Logo horizontal principal

Uso recomendado para:

- Sitio web.
- Aplicación de escritorio o web.
- Encabezados.
- Documentos.
- Presentaciones.
- Material corporativo.

### 3.2 Logo vertical

Uso recomendado para:

- Portadas.
- Materiales con formato cuadrado.
- Redes sociales.
- Espacios reducidos en anchura.
- Aplicaciones móviles.

### 3.3 Isotipo

Uso recomendado para:

- Favicon.
- Icono de aplicación.
- Avatar.
- Botones de navegación.
- Marcadores de producto.
- Espacios donde el wordmark no sea legible.

### 3.4 Versiones para fondos oscuros

Sobre fondos oscuros:

- Mantener las barras azul, verde y naranja.
- Usar el wordmark en blanco o en una combinación de blanco y azul.
- Mantener contraste suficiente.
- No añadir sombras o brillos innecesarios.

### 3.5 Versión monocromática

Para impresiones, grabados, sellos o restricciones de producción:

- Usar una sola tinta.
- Mantener la geometría original.
- No sustituir el diamante por otro símbolo.
- No alterar las proporciones de las barras.

## 4. Paleta de color

La identidad utiliza una paleta plana, sin degradados.

| Color | HEX | Uso principal |
|---|---|---|
| Azul noche | `#0F2D5B` | Confianza, estructura, wordmark, textos principales |
| Azul planificación | `#2563EB` | Tecnología, planificación, acciones principales |
| Verde progreso | `#16A34A` | Avance, ejecución, estados positivos |
| Naranja hitos | `#F59E0B` | Hitos, alertas visuales, puntos de atención |
| Gris soporte | `#E5E7EB` | Fondos, bordes y superficies secundarias |
| Blanco | `#FFFFFF` | Fondos limpios y contraste |

### Reglas de color

- No usar degradados en el logotipo.
- No aplicar transparencias que reduzcan la legibilidad.
- No cambiar arbitrariamente el color del diamante.
- No utilizar colores fluorescentes o saturaciones ajenas a la paleta.
- Mantener el azul noche como color estructural.
- Reservar el naranja para hitos y acentos, no para grandes bloques de texto.

## 6. Área de seguridad

Debe mantenerse un área libre alrededor del logotipo equivalente, como mínimo, a la altura de la barra azul del isotipo.

Dentro de esta zona no deben aparecer:

- Textos.
- Fotografías.
- Bordes.
- Otros logotipos.
- Elementos de interfaz.
- Líneas decorativas.

En tamaños pequeños, aumentar el área de seguridad cuando el fondo sea complejo.

## 8. Usos incorrectos

No se permite:

1. Utilizar degradados.
2. Deformar o estirar el logotipo.
3. Cambiar la posición de las barras.
4. Girar el isotipo.
5. Cambiar el diamante por otro símbolo.
6. Usar el nombre completamente en mayúsculas.
7. Añadir sombras, biseles o efectos 3D.
8. Cambiar arbitrariamente la paleta.
9. Colocar el logo sobre fondos que impidan su lectura.
10. Separar el wordmark del isotipo sin respetar una composición aprobada.
11. Modificar la proporción entre `Open`, `Gantt` y `Lab`.
12. Añadir contornos o efectos decorativos.

## 12. Nota técnica sobre el SVG

El SVG incluido contiene:

- Formas vectoriales para las barras del cronograma.
- Línea temporal vectorial.
- Diamante de hito vectorial.
- Textos editables.
- Colores planos definidos mediante códigos HEX.
- Identificadores (`id`) para facilitar su edición en Figma, Illustrator, Inkscape o editores de código.

Para obtener una versión convertida completamente a curvas, puede abrirse el SVG en un editor vectorial y convertir los textos a trazados. La versión incluida conserva los textos como texto editable para facilitar cambios futuros.
